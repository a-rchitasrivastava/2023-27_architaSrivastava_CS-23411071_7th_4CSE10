# Zivika Accessories – UI/UX Design

## Project Overview

Zivika Accessories is a UI/UX design project for an online accessories and jewellery shopping website. The project focuses on creating a clean, attractive, and user-friendly interface for browsing and exploring different jewellery categories.

The complete interface was designed and prototyped using Figma.

## Project Objectives

- To design a modern and user-friendly accessories shopping interface.
- To provide easy navigation between different product categories.
- To create an attractive and consistent visual design.
- To improve the overall user experience of an online jewellery store.
- To create an interactive prototype demonstrating the website flow.

## Design Tool

- Figma

## UI/UX Design Process

The project followed a basic UI/UX design process:

1. Understanding the purpose and target users
2. Planning the website structure
3. Creating page layouts and wireframes
4. Designing the user interface
5. Creating product category pages
6. Creating the login/signup interface
7. Connecting screens into an interactive prototype
8. Reviewing and improving the visual design

## Key Screens

### Home Page
The home page introduces the Zivika brand and provides navigation to different jewellery categories.

### Product Category Pages
The project includes category pages for:

- Rings
- Bracelets
- Pendants
- Anklets

### Login Page
A login/signup interface was designed to provide users with access to their account.
